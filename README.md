# 🚦 Traffic Management System

![Traffic Light](https://greenipservices.com/wp-content/uploads/2022/02/dsddsff26.jpg)

## 📌 Project Overview
The **Traffic Management System** is a fully developed AI-powered solution that optimizes traffic signals using **OpenCV, YOLO v8, and Raspberry Pi**. It enhances traffic flow efficiency by detecting vehicle density and adjusting signal timings dynamically.

## 🎯 Features
✅ **Real-time Vehicle Detection** using YOLO v8  
✅ **Dynamic Traffic Signal Control** based on congestion levels  
✅ **Edge Computing** with Raspberry Pi for faster processing  
✅ **OpenCV-based Image Processing** for vehicle detection  
✅ **Optimized Traffic Flow** to reduce congestion and travel time  

---

## 🔄 Workflow
The workflow of this project follows these steps:
```
YOLO ----> VEHICLE COUNT ----> EVALUATION ----> DECISION MAKING
```
According to the vehicle count, the system dynamically updates the signal timing.
